# 日常の会話から探究テーマを見つける

家庭や学校での何気ない会話にある「面白い」「どうして」を、研究できる問いへ育てるプロジェクトです。中高生と、その探究活動を支える教員や保護者に向けて、身近な気づきと学問のつながり、調べ方、確かめ方を具体例で紹介します。

探究活動は、本物の研究の入口です。身近な好奇心に、プロの研究者も取り組む重要で面白い問いが含まれていることを、先行研究と具体的な活用例から実感できるようにします。始めやすさのために研究の広がりを削らず、小さな調査から記憶の理解、AIの表現設計、学習支援の個別最適化へ至る道筋を示します。

中高生向けの入口は [日常から探究へ](https://airpocket-soundman.github.io/everyday-inquiry/) です。資料を更新してmainブランチへ反映すると、GitHub Pagesも自動更新されます。

研究テーマが見つからないとき、必要なのは特別な体験だけではありません。自分の気づきに関係する学問や測定方法を知ることで、いつもの会話が研究の入口になります。テーマ探しの難しさには、知識だけでなく、時間、相談相手、調査環境、失敗への不安も関わります。本プロジェクトは、知識の橋渡しと小さく試せる方法を提供します。

## 最初の二つの事例

| 会話の気づき | 探究への展開 | 資料 |
| --- | --- | --- |
| ヒストグラムを思い出す前にヒエログリフやピクトグラムの絵が浮かぶ | 画像と言語の記憶、音や文字の類似、単語のベクトル化 | [記憶と単語の類似性](docs/01-memory-and-word-similarity.md) |
| 数学は大好きな人と大嫌いな人に分かれる気がする | 教科嗜好の分布、個人の組み合わせ、学習支援の比較 | [教科の嗜好と学習支援](docs/02-subject-preferences.md) |

## 探究を始める

1. 印象に残った会話や自分の気づきを、個人が特定されない形で書き留める。
2. 観察した事実と、自分の解釈や予想を分ける。
3. 関係する学問や先行研究を読み、問いを一つに絞る。
4. 何をどう測れば予想を確かめられるか決める。
5. 小さく試し、予想と違った結果も記録する。

[探究テーマのテンプレート](templates/inquiry-theme.md)と[教科嗜好の質問票](templates/subject-preference-survey.md)を使えます。調査前に[参加者とデータの扱い](docs/research-practice.md)を確認してください。

## 編集方針

会話の面白さを残しながら、既知の知見、本人の経験、検証前の仮説を区別します。学問名を紹介するだけでなく、中高生が実施できる測定へつなげます。結論が出ないことや予想が外れることも、探究の成果として扱います。

現段階は解説と研究計画の初期版です。実際の参加者データや、二峰性・学習効果を示す実測結果は含みません。

- 単語類似度の比較教材と、架空データによる集計教材を追加する。
- 新しい会話事例を同じテンプレートで蓄積する。
- 生徒や教員の感想から、説明と研究手順を改善する。
