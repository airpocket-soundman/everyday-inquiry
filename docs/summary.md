# 一枚でわかる まとめページ

二つの事例は内容が長いので、全体像だけをここにまとめます。詳しくは各記事を読んでください。

## 探究の流れ

1. 会話や気づきを書き留める。
2. 事実と自分の解釈を分ける。
3. 近い現象の名前と先行研究を探す。
4. 問いを一つに絞り、測り方を決める。
5. 小さく試し、予想と違った結果も記録する。

最初の調査は、研究者も行う「予備調査」にあたります。同じ問いの立て方と落とし穴を経験することが、本物の研究の入口です。

## 事例1：記憶と単語の類似性

**会話** ヒストグラムを思い出す前に、ヒエログリフやピクトグラムの絵が浮かぶ。

| 段階 | 内容 |
| --- | --- |
| 研究の現場 | 舌先現象（Brown & McNeill 1966）、拡散活性化（Collins & Loftus 1975）、近隣活性化モデル（Luce & Pisoni 1998）、ブーバ／キキ（Bremnerら 2013）、画像優位性と二重符号化 |
| 「似ている」を数にする | 位置ごとの文字一致、編集距離、音の特徴、nグラム、学習した意味ベクトル、人の連想評定 |
| AIへの展開 | word2vec、fastText、Sentence-BERT、CLIP |
| 最初に試すこと | 似ていると感じる言葉を10組集め、同じ文字を数えて自分の順位と比べる |
| 研究計画 | 文字一致と母音一致のどちらが音の類似度評定と対応するか。関連する絵が用語の記憶を助けるか |

**手法の選び方** 最も複雑な手法が常に最善ではない。説明のしやすさ、必要なデータ量、予測したい現象で選ぶ。

[詳しく読む](01-memory-and-word-similarity.md)

## 事例2：教科の好みと学習支援

**会話** 数学は好きな人と嫌いな人に分かれる気がする。国語はそうでもないのでは。

| 段階 | 内容 |
| --- | --- |
| 研究の現場 | 興味の発達（Hidi & Renninger 2006）、期待価値理論、教科ごとの自己概念（Marsh 1986）、潜在プロフィール分析、適性処遇交互作用（Cronbach & Snow 1977） |
| 分布を調べる | 5段階回答を、まず人数と割合の棒グラフで示す。二つの山は仮説として確かめる |
| 個人を表す | 好み・得意感・不安・価値を教科ごとに並べる（ベクトル）。固定的な型に名付けない |
| 支援を考える | 困りごとの原因を確かめて支援候補を作り、比較実験で効果を測る |
| 最初に試すこと | 先生と相談し、数人に質問票を答えてもらい、分布を棒グラフにする |

**注意** 「好きな方法」と「成績が上がる方法」は別。学習スタイルに合わせた教材で成績が上がるという仮説に、十分な証拠はない。

## 二つの事例に共通する考え方

- 観察したこと、既知の知見、検証前の仮説を区別する。
- 「自分にはこう感じられた」と「参加者にも同じ傾向があった」を区別する。
- 関連があっても原因とは限らない。
- 予想が外れても、記録すれば発見になる。

## 調査の前に確認すること

- 参加は任意で、断れることを説明する。
- 実名、成績、家庭事情などの不要な情報は集めない。
- 実データは公開リポジトリに置かない。
- 学校で行うときは、先生と相談する。
