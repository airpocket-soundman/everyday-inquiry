# 教科の嗜好の分布から学習支援を考える

「数学は好きな人と嫌いな人に分かれる。国語はそこまで分かれない気がする」。この会話から、教科ごとの好みの分布と、一人ひとりに合う支援の研究へ進めます。ただし「数学は二つの山になる」は、実際に測って確かめる仮説です。

## 三つの問い

1. 数学の好き嫌いの分布は、同じ参加者の他教科の分布とどう違うか。
2. 好き嫌い、得意感、不安、役立つと思う程度は、どのように関係するか。
3. それらの特徴に応じた支援は、理解度や学習への参加を改善するか。

最初の調査で分かるのは分布と関連です。原因や支援の効果を確かめるには、追加の聞き取り、時間を追った測定、支援方法の比較が必要です。

## 関係する学域

| 学域 | つながる問い |
| --- | --- |
| 教育心理学 | 興味、自己効力感、不安は学習とどう関係するか |
| 教科教育 | どの単元や課題でつまずくか |
| 統計学 | 分布の山や集団の違いをどう確かめるか |
| データ科学 | 複数教科の特徴をどう表現し比較するか |
| 教育社会学 | 授業環境や学習機会の違いがどう関係するか |

## 好き嫌いと得意不得意を分ける

数学が好きでも解けない人、解けても好きではない人は、別の支援を必要とするかもしれません。数学不安と数学の成績の関係を扱ったレビューでは、成績から不安、不安から成績という双方の影響の可能性が論じられています。今回の嗜好調査だけで因果の向きは決められません。[Careyら 2016](https://www.frontiersin.org/journals/psychology/articles/10.3389/fpsyg.2015.01987/full)

「理科は暗記型、数学は思考型」と教科全体を決めると、実験、考察、説明、計算などの違いが隠れます。まず教科を比較し、次に単元や活動へ分けます。国語にも語彙、読解、作文、発表があり、入りやすさは人や活動によって異なります。

## 小さく始める調査

[質問票](../templates/subject-preference-survey.md)を使い、数学・理科・国語・社会・英語について、好み、得意感、不安、価値の認識をそれぞれ5段階で尋ねます。未履修・分からない・回答しないは中立の3に混ぜず、別に記録します。研究範囲は例えば同じ学年の協力者とし、人数と募集方法を明記します。

全教科に同じ尺度と期間を使い、「最近1か月の授業」を思い浮かべてもらいます。質問票は本調査の前に数人に読んでもらい、意味が通じるか確かめます。自作の単一項目は手軽ですが、複雑な心理特性の精密な測定や診断には使えません。

## 二つの山をどう確かめるか

5段階の回答は順序尺度なので、まず1〜5それぞれの人数と割合を棒グラフで示します。連続量のように扱って滑らかな曲線だけを描くと、測っていない細かな形まで見えてしまいます。分母と欠測数を教科ごとに併記します。

例えば「1が12人、2が8人、3が3人、4が9人、5が13人」なら、両端に多い形です。これは説明用の架空例で実測値ではありません。この形だけで二つの固定的な集団が存在するとはいえません。

予め「1・2を否定側、4・5を肯定側」と定め、両側の割合と3の割合を教科間で比べると、二極化の記述ができます。ただし、それは正式な二峰性の証明とは異なります。発展としてより細かな尺度や混合分布モデルを検討できますが、尺度変更だけで山が見えることもあり、十分な人数とモデルの吟味が必要です。

同じ人が複数教科に答えるため、教科の回答は独立ではありません。少人数ならまず記述的な比較に集中し、学年やクラスを混ぜたことで山ができていないかも確認します。都合のよい区切りや集団だけを選ばず、予め決めた集計と、追加で試した集計を区別します。

## 個人の組み合わせをベクトルで表す

好みを `p = [数学, 理科, 国語, 社会, 英語]` と並べれば、一人の嗜好を五つの数値で表せます。架空の例 `p = [5,4,2,3,2]` は、数学と理科の好みが比較的高い人です。得意感、不安、価値についても別の五次元ベクトルを作れます。

好みだけのベクトルは分かりやすい一方、同じ好みでも困りごとが違うことを表せません。四つの尺度を連結すると20次元になりますが、数値を同じ間隔と見なす仮定や、何に重みを置くかを説明する必要があります。

最初は教科間の関連や個人別の表を眺めます。発展としてクラスタリングで似た回答をまとめられますが、少人数ではまとまりが不安定です。「理系型」「暗記型」と固定的に名付けず、募集した集団とその時点の回答のまとまりとして扱います。20項目から組み合わせを探すと偶然の関連も増えるため、最初に調べる関係を少数に絞ります。

## 支援の候補を作る

次は、嗜好の分類から直接処方を決めるのではなく、困りごとを確かめて支援候補を作る段階です。以下は検証前の提案であり、効果が確立した個別処方ではありません。

| 回答と聞き取りから見える困りごと | 支援候補 | 確かめる指標 |
| --- | --- | --- |
| 好きだが基礎でつまずく | 前提知識に戻る短い課題 | 同程度の確認問題の正答率 |
| 解けるが面白さや価値を感じない | 本人の関心に結びつく応用課題 | 参加意欲と応用問題の理解 |
| 不安が強く時間制限で困る | 時間制限を弱め、段階的な課題を使う | 不安と正答率の変化 |
| 説明文や用語の理解で止まる | 用語の確認と図による説明 | 自分の言葉での説明と正答率 |
| 暗記だけでは理解が続かない | 理由の説明と取り出す練習を組み合わせる | 後日の再テスト |

「好きな方法」と「成績が改善する方法」は別です。学習者を視覚型・聴覚型などに分類し、その型に教材を合わせれば成績が上がるという仮説について、Pashlerらのレビューは採用を正当化する十分な証拠がないと結論しました。本プロジェクトでも嗜好を固定的な能力分類に変えず、効果を測ります。[Pashlerら Learning Styles](https://bjorklab.psych.ucla.edu/wp-content/uploads/sites/13/2016/07/Pashler_McDaniel_Rohrer_Bjork_2009_PSPI.pdf)

## 支援方法を比較する研究へ進む

最初の実験は一教科、一単元、二つの支援方法に絞ります。例えば、通常の説明と、図を加えた説明を比較します。事前の確認問題と嗜好を記録してから参加者を無作為に割り当て、学習時間、扱う内容、事後問題の難しさをそろえます。可能なら翌週も確認し、直後だけの改善と区別します。

本人の嗜好に応じた最適化を主張するには、全体でどちらが良いかだけでは足りません。「どの特徴の人に、どの方法の効果が大きいか」という交互作用を、予め決めた少数の特徴で調べる必要があります。少人数の予備調査で各人の最適法まで決めず、別の参加者でも再現するか確かめます。

無作為割り当てが難しく順番に試す場合は、先に学んだ効果と単元の違いが混ざります。方法の順番を入れ替え、同程度の課題を用意しても、その限界を報告します。支援を受けなかった人にも学習機会を確保し、参加や成績評価と研究協力を結びつけません。

## 最初の成果物

教科別の回答分布、好みと得意感・不安の関係、匿名化した自由記述の要約、次に試す支援候補をまとめます。「数学は二峰性だった」という結論を目指すのではなく、「今回の参加者と質問ではこう分布した」と示すことから始めます。
