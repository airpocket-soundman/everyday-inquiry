# 教科の好みと学習経験を調べる質問票

この質問票は探究活動のための自作の予備調査用です。診断や成績評価には使いません。実施者は調査の目的、任意参加、利用範囲、保管と削除の予定、質問先を説明し、学校の手順に従って必要な同意を得てから配布してください。

最近1か月の授業を思い浮かべて答えてください。答えに正解はありません。回答しない項目があっても構いません。名前、出席番号、成績は書かないでください。

## 回答方法

各文について、1「まったく当てはまらない」、2「あまり当てはまらない」、3「どちらともいえない」、4「やや当てはまる」、5「とても当てはまる」から選んでください。「未履修」「分からない」「回答しない」は数字と別に記録します。

| 文 | 数学 | 理科 | 国語 | 社会 | 英語 |
| --- | --- | --- | --- | --- | --- |
| この教科の学習が好きだ | | | | | |
| この教科の課題を自分で解けると思う | | | | | |
| この教科の課題に取り組むとき不安を感じる | | | | | |
| この教科で学ぶことは自分にとって役立つと思う | | | | | |

教科の順番による影響を調べる場合は、列の順番を変えた版も使います。不安の項目は数字が大きいほど不安が強いので、単純に全項目を足して一つの「良さ」にしないでください。

## 任意の自由記述

- 一つの教科を選び、好きまたは好きではないと感じる具体的な活動や場面を書いてください。
- 学習するとき困ることがあれば書いてください。
- 試してみたい助け方があれば書いてください。

先生や友人の名前、個人が分かる出来事は書かないでください。実施者は公開前に自由記述を確認し、特定につながる表現を除いた要約を使います。
